# ⭐ 1. CORE GAME LOOP (MATCH-TO-MATCH)

This is the *heartbeat* of your game — the loop the player experiences every match.

```
[Start Match]
     ↓
[Draw Action Cards → Use Commands → Gain Momentum]
     ↓
[Real-Time Football Play → AI Executes Strategy]
     ↓
[Score Goals → Manage Risk → Use Team Commands]
     ↓
[Match Ends → XP + Rewards + Ratings]
     ↓
[Grow Players + Build Better Decks]
     ↓
[Queue Next Match]
```

Let’s break it down:

### 🔹 Step 1 — Start Match

* Select squad
* Select formation
* Select 5 tactical cards
* Enter top-down pixel match

### 🔹 Step 2 — Execute Commands (The Fun Loop)

* Pass / Dribble / Shoot / Tackle / Press / Through Ball
* Directional input for certain commands
* Manage cooldowns

### 🔹 Step 3 — Tactical Momentum

* Use Team Command Cards
* Trigger momentum shifts
* Manage risk/reward
* AI reacts to your tactical identity

### 🔹 Step 4 — Match Outcome

* XP for player cards
* Manager XP
* Rewards: coins, tokens, perks
* Rating for each player

This loop repeats forever with increasing mastery.

# ⭐ 3. ECONOMY LOOP (CURRENCIES + PROGRESSION INPUTS)

This part ties match performance to long-term upgrades.

```
[Matches] → Grant → [Coins + Tokens + Packs]
        ↓                  ↓
   [Facilities] ← [Currencies] → [Card Upgrades]
```

### Primary Currencies

* **Coins** (soft): earned from matches, used to upgrade facilities + buy packs
* **Training Tokens**: used to boost player stats within caps
* **Perk Shards**: used to unlock/upgrade perks
* **Gems** (optional premium): cosmetics, boosters, convenience

### Economy Intent

* No hard paywalls
* Progression curve ramps smoothly
* Each match contributes meaningfully
* Seasonal rewards accelerate progress

### Daily/Weekly Sinks

* Facility upgrades
* Perk rerolls
* Training sessions
* Scouting refreshes

This ensures players always have something to work toward.
