# 🅞 — **MATCH COMMENTARY FLOWS (LIGHTWEIGHT TEXT POP-UPS)**

### *“Micro-narration for a tactical football RPG”*

Fast, readable, useful — *not bloated like real-world commentary.*

---

# ⭐ 1. Commentary Philosophy

### ✔ 1. Short

Usually **1 line**, max **2 lines**.

### ✔ 2. Tactical

Explain the **gameplay reason**, not flavor fluff:

* “Overload triggered.”
* “High press successful.”
* “Dribble penetrated the line.”

### ✔ 3. Positive-focused

Avoid negativity spam.

### ✔ 4. Player-driven personality

Archetypes shine through comments.

### ✔ 5. Trigger-based

Every popup corresponds to **clear in-match triggers**, not random chatter.

---

# ⭐ 10. UI Integration Rules

### ✔ Always 1 line if possible

### ✔ Fade-in: 150 ms

### ✔ On-screen: 1.2–2.4 sec

### ✔ Fade-out: 150 ms

### ✔ No more than **1 popup at a time**

### ✔ Queue limit: **3 messages max**

### ✔ Team-colored accent bar on left edge

### ✔ Pixel font only (6px or 8px)

Placement example:

```
 ┌───────────────────────────┐
 │  🛡 Defensive wall formed.│
 └───────────────────────────┘
```

---

# ⭐ 11. Commentary Rules to Prevent Spam

* **Cooldown of 4 sec** between pop-ups (except goals).
* Never repeat same line twice within 90 sec.
* High-intensity events override low-intensity ones.
* Archetype personality lines use **per-player cooldowns**.
* Momentum messages only when crossing thresholds
  (e.g., -0.2 / +0.2 / -0.5 / +0.5).
